## What is Big O notation?

Big O notation describes the upper bound of an algorithm's growth rate — how its runtime or memory usage scales as the input size increases. It gives you a way to compare algorithm efficiency independent of hardware or implementation details.

The notation expresses worst-case complexity in terms of input size `n`. Lower-order terms and constants are dropped, leaving only the dominant factor.

## Growth rates

| Big O notation | Type | 10 elements | 100 elements | 1000 elements |
| :--- | :--- | ---: | ---: | ---: |
| O(1) | Constant | 1 | 1 | 1 |
| O(log N) | Logarithmic | 3 | 6 | 9 |
| O(N) | Linear | 10 | 100 | 1,000 |
| O(N log N) | n log(n) | 30 | 600 | 9,000 |
| O(N²) | Quadratic | 100 | 10,000 | 1,000,000 |
| O(2^N) | Exponential | 1,024 | 1.26e+29 | 1.07e+301 |
| O(N!) | Factorial | 3,628,800 | 9.3e+157 | 4.02e+2567 |

## Data structure operations

Average-case complexity for common operations. `n` denotes linear time; `-` means the operation is not supported.

| Data structure | Access | Search | Insertion | Deletion |
| :--- | :---: | :---: | :---: | :---: |
| Array | n | n | n | n |
| Stack | n | n | 1 | 1 |
| Queue | n | n | 1 | 1 |
| Linked list | n | n | 1 | n |
| Hash table | - | n | n | n |
| Binary search tree | n | n | n | n |
| B-tree | log(n) | log(n) | log(n) | log(n) |
| Red-black tree | log(n) | log(n) | log(n) | log(n) |
| AVL tree | log(n) | log(n) | log(n) | log(n) |
| Bloom filter | - | 1 | 1 | - |

## Sorting algorithms

| Name | Best | Average | Worst | Memory | Stable |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Bubble sort | n | n² | n² | 1 | Yes |
| Insertion sort | n | n² | n² | 1 | Yes |
| Selection sort | n² | n² | n² | 1 | No |
| Heap sort | n log n | n log n | n log n | 1 | No |
| Merge sort | n log n | n log n | n log n | n | Yes |
| Quick sort | n log n | n log n | n² | log(n) | No |
| Shell sort | n log n | depends | n(log n)² | 1 | No |
| Counting sort | n+r | n+r | n+r | n+r | Yes |
| Radix sort | n*k | n*k | n*k | n+k | Yes |

`r` = range of input values; `k` = number of digits in the largest number.
