Dynamic programming (DP) solves problems by breaking them into overlapping subproblems and storing results to avoid redundant computation. It applies to both **top-down** (memoization) and **bottom-up** (tabulation) strategies.

<Note>
  Many DP algorithms in this repo are also covered under other sections (Strings, Sets, Graphs). This page highlights the DP angle specifically.
</Note>

## Fibonacci Number `B`

The classic DP example. The iterative bottom-up approach avoids the exponential cost of naive recursion.

```javascript fibonacci.js
export default function fibonacci(n) {
  const fibSequence = [1];
  let currentValue = 1;
  let previousValue = 0;

  if (n === 1) return fibSequence;

  let iterationsCounter = n - 1;
  while (iterationsCounter) {
    currentValue += previousValue;
    previousValue = currentValue - previousValue;
    fibSequence.push(currentValue);
    iterationsCounter -= 1;
  }

  return fibSequence;
}

fibonacci(8); // [1, 1, 2, 3, 5, 8, 13, 21]
```

**Complexity:** O(n) time, O(n) space (for the sequence array)

## Unique Paths `B`

Count all unique paths from the top-left to bottom-right of an m×n grid (only right/down moves). Solved with DP and Pascal's Triangle.

**Source:** `src/algorithms/uncategorized/unique-paths/`

```javascript unique-paths-usage.js
import uniquePaths from './uniquePathsDynamic';
uniquePaths(3, 3); // 6 unique paths in a 3x3 grid
```
