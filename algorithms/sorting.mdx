Sorting is one of the most fundamental algorithm categories. This repository includes 10 sorting algorithm implementations, each with tests and a README. All are labeled **B** (Beginner).

**Source:** `src/algorithms/sorting/`

## Complexity comparison

| Algorithm | Best | Average | Worst | Memory | Stable |
|-----------|------|---------|-------|--------|--------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | Yes |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | Yes |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) | No |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) | O(1) | No |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Yes |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | No |
| Shell Sort | O(n log n) | depends on gap | O(n (log n)²) | O(1) | No |
| Counting Sort | O(n + r) | O(n + r) | O(n + r) | O(n + r) | Yes |
| Radix Sort | O(n × k) | O(n × k) | O(n × k) | O(n + k) | Yes |
| Bucket Sort | O(n + k) | O(n + k) | O(n²) | O(n) | Yes |

`r` = largest number in array, `k` = length of longest key / number of buckets

## Bubble Sort

Repeatedly steps through the array, compares adjacent elements, and swaps them if out of order. Stops early if no swaps occurred in a pass.

```javascript bubble-sort.js
import Sort from '../Sort';

export default class BubbleSort extends Sort {
  sort(originalArray) {
    let swapped = false;
    const array = [...originalArray];

    for (let i = 1; i < array.length; i += 1) {
      swapped = false;
      for (let j = 0; j < array.length - i; j += 1) {
        if (this.comparator.lessThan(array[j + 1], array[j])) {
          [array[j], array[j + 1]] = [array[j + 1], array[j]];
          swapped = true;
        }
      }
      if (!swapped) return array;
    }
    return array;
  }
}
```

## Merge Sort

A divide-and-conquer algorithm that splits the array in half recursively, sorts each half, then merges the sorted halves. Always O(n log n) regardless of input order.

```javascript merge-sort.js
export default class MergeSort extends Sort {
  sort(originalArray) {
    if (originalArray.length <= 1) return originalArray;

    const middleIndex = Math.floor(originalArray.length / 2);
    const leftSorted = this.sort(originalArray.slice(0, middleIndex));
    const rightSorted = this.sort(originalArray.slice(middleIndex));

    return this.mergeSortedArrays(leftSorted, rightSorted);
  }

  mergeSortedArrays(leftArray, rightArray) {
    const sorted = [];
    let l = 0, r = 0;

    while (l < leftArray.length && r < rightArray.length) {
      if (this.comparator.lessThanOrEqual(leftArray[l], rightArray[r])) {
        sorted.push(leftArray[l++]);
      } else {
        sorted.push(rightArray[r++]);
      }
    }

    return sorted.concat(leftArray.slice(l)).concat(rightArray.slice(r));
  }
}
```

## Quick Sort

Selects a pivot and partitions the array into elements less than and greater than the pivot, then recursively sorts each partition. Both in-place and non-in-place implementations are included.

```javascript quick-sort-usage.js
import QuickSort from './quick-sort/QuickSort';

const sorter = new QuickSort();
sorter.sort([3, 1, 4, 1, 5, 9, 2, 6]); // [1, 1, 2, 3, 4, 5, 6, 9]
```

## Heap Sort

Builds a max-heap from the array, then repeatedly extracts the maximum element to produce the sorted result. O(n log n) guaranteed, in-place.

## Insertion Sort

Builds the sorted array one element at a time by inserting each element into its correct position. Efficient for small or nearly sorted datasets.

## Selection Sort

Repeatedly finds the minimum element from the unsorted portion and swaps it to the front. Simple but always O(n²).

## Shell Sort

A generalization of insertion sort that allows the exchange of elements that are far apart. The gap sequence determines performance.

## Counting Sort

Non-comparison sort for integers in a known range. Creates a count array and reconstructs the sorted output in O(n + r) time.

## Radix Sort

Non-comparison sort that sorts digit by digit from least significant to most significant. O(n × k) time where k is the number of digits.

## Bucket Sort

Distributes elements into buckets, sorts each bucket (typically with insertion sort), then concatenates the results.

## Using the Sort base class

All sorting implementations extend the `Sort` base class from `src/algorithms/sorting/Sort.js`. The `Sort` class provides a `comparator` (a `Comparator` instance) and a `callbacks.visitingCallback` for instrumentation.

```javascript sort-with-custom-comparator.js
import MergeSort from './merge-sort/MergeSort';

const sorter = new MergeSort({
  compareCallback: (a, b) => {
    if (a.value === b.value) return 0;
    return a.value < b.value ? -1 : 1;
  },
});

sorter.sort([{ value: 3 }, { value: 1 }, { value: 2 }]);
// [{ value: 1 }, { value: 2 }, { value: 3 }]
```
