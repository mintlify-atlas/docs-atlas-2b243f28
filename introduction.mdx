## What is this repository?

This repository contains JavaScript-based implementations of many popular algorithms and data structures. It is designed as a learning resource for computer science fundamentals.

Each algorithm and data structure has its own dedicated README that includes:

- A plain-language explanation of how it works
- Complexity analysis (time and space)
- Links for further reading, including YouTube videos

## Difficulty labels

Entries are labeled to indicate their complexity:

- `B` — **Beginner**: Suitable for those new to algorithms and data structures
- `A` — **Advanced**: Requires familiarity with foundational concepts
